# Kaziro Frontend

Next.js App Router frontend for Kaziro.

## Commands

```bash
pnpm install
pnpm dev
pnpm lint
pnpm typecheck
pnpm build
pnpm test:e2e
```

## Layout

```text
frontend/
├── src/app/          # App Router route groups and pages
├── src/components/   # reusable UI and domain components
├── src/lib/          # API clients, stores, forms, shared helpers
├── e2e/              # Playwright tests
└── public/
```
