# Roadmap

This roadmap tracks product phases at a high level. Use issues or `PLAN.md`
for task-level execution.

## Phase 1: Foundation

- Django project with typed settings, Django Ninja API, and health checks.
- PostgreSQL schema with pgvector support.
- Celery worker and Beat scheduling.
- Next.js application shell with auth, onboarding, and dashboard routes.

## Phase 2: Job Discovery

- Job-source integrations.
- User job-search preferences.
- Scheduled fetches.
- Raw job normalization.

## Phase 3: Evaluation And Research

- Parser, evaluator, research, and document LangGraph workflows.
- Fit scoring and classification.
- Company research summaries.
- Pipeline status and notifications.

## Phase 4: Documents And Applications

- Tailored CV and cover-letter generation.
- Document preview/download.
- Application tracking.
- User settings and notification controls.

## Phase 5: Operations

- Production deployment hardening.
- Observability dashboards and alerts.
- Cost tracking for LLM and external API usage.
- Reliability improvements for queue processing.
